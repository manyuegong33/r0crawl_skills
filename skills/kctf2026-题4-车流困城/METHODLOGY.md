# 通用方法论：Heaven's Gate + VEH VM + 魔改 AES + 多项式根类 CrackMe

> 适用题型：32 位 PE 外壳藏 64 位核心、用异常处理模拟指令集、根据环境（父进程/PEB/调试器）选真假算法、自定义 Base64、魔改 AES、最终归结为多项式整数根。典型特征：Serial 超长（几千字符）、固定头尾、字符表 64 个可打印字符。

## 一、题型识别特征

- 32 位 PE，但入口有 `push 0x33; retf`（Heaven's Gate 切 long mode）。
- 出现 `in/out/int3` 等特权指令，但并非 I/O——是 VEH 捕获后按 opcode 分派的自定义 VM 指令。
- 枚举父进程并做哈希（djb2 等），仅白名单（explorer/cmd/powershell）进真算法。
- PEB BeingDebugged 字节在多处被加进密钥（如 +0x1A、+0x40 叠加成 0x5A），任一 patch 落假路径。
- Serial 固定长度、固定头尾、正文 64 字符表（自定义 Base64 变体）。
- 最终明文是"N 组 M 次多项式的整数根"按规则拼接。

## 二、通用推导流程（5 步）

### 第 1 步：确认真实执行环境
- 识别 Heaven's Gate，分别反汇编 32/64 两套代码。
- 建立 opcode → VEH handler 的自定义 ISA 表（如 0xED 反调试、0xEE 长度校验、0xEF 派生密钥、0xEC 混淆跳转）。
- 记录父进程哈希、PEB 字节、调试寄存器对算法状态的影响，列出"真路径条件清单"。

### 第 2 步：恢复自定义编码（Serial 外层）
- 确认 Serial 结构：头尾固定字符 + 正文。
- 对正文每位置 i，字符表下标 a_i 与真实 6-bit 值 v_i 的关系通常是 `v_i = (a_i + C1 + C2*i) mod 64`，反推 `a_i = (v_i - C1 - C2*i) mod 64`。
- 解出密文字节，按块分组（如 16 字节/块）。

### 第 3 步：逆向魔改 AES 层
- 用输入差分确认模式（ECB：只同一块输出变化）。
- 注意状态布局：可能按列存储、按行运算，用逆列混合+右移行变换，不能直接套标准 AES 库。
- 在异常上下文中轮询线程栈的 CONTEXT/XMM 寄存器，不暂停、不写内存地采集相邻轮状态；差分恢复 GF(2^8) 多项式（如 0x11B）下的 S 盒、轮密钥、首轮异或值。
- 留意每轮线性层后额外 XOR 的常量（如 0x40），重实现时保留。

### 第 4 步：求解多项式根并构造明文
- 用户名经 hash（如 31-base + Murmur fmix），循环取 `state & 0x3fff` 去重得到 N 行。
- 每行若干压缩 BCD 系数，解密密钥通常是 `base = (group*C1) XOR (coef_index*C2)`。
- 每组 M 次多项式的整数根即 M 个数字：常规组整数范围因式分解 + Horner 验证；被篡改的组枚举常数项因子逐一筛选互异整数根。
- 根按组内升序、以分隔符连接，注意前导零补齐和 NUL 对齐到块大小。

### 第 5 步：验证与交付
- 正向：明文 → 魔改 AES 加密 → 位置相关 Base64 编码 → 加头尾 → Serial。
- 先改单字符做差分确认每块走真路径；最后在原始未 patch 程序、白名单父进程、无调试器下验证 Successful。

## 三、验证清单

- [ ] 32/64 两套代码都已反汇编，Heaven's Gate 切换点明确。
- [ ] opcode→handler 表完整，没有简单 NOP 异常指令。
- [ ] 真路径条件（父进程/PEB/调试器）全部列出并满足。
- [ ] 差分确认 ECB 与状态布局，密钥从 CONTEXT 只读采样恢复。
- [ ] 整数根用精确因式分解/Horner，篡改组单独处理。
- [ ] 明文长度、NUL 对齐、位置相关编码严格满足。

## 四、常见坑

| 坑 | 表现 | 规避 |
|---|---|---|
| 直接 NOP 异常指令 | VM 流程断裂 | 建立 opcode→handler 表，按语义模拟 |
| 套标准 AES 库 | 解密结果乱码 | 先差分确认布局（行/列、移位方向） |
| patch 反调试 | 落入假路径 | 用白名单父进程+无调试器采样，不改代码 |
| 忽略每轮额外 XOR 常量 | 密钥恢复错 | 重实现时逐轮对比中间态 |
| 篡改组当常规组解 | 根不互异/无解 | 枚举常数项因子逐一筛选 |
| 前导零/NUL 对齐错 | 长度校验失败 | 严格按题面长度约束构造 |
