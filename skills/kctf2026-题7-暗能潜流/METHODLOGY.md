# 方法论：自定义分块编码/加密 逆向通用流程

> 适用题型：密文是定长块的倍数，块内"固定骨架 + 有效数据位"，明文按 N 字节分块，
> 经"半字节/字节级变换（含密钥周期）+ 位置重排"，尾块结构随 `len % N` 变化。
> 典型特征：给你几组 已知明文↔密文 样例 + 一段待解密的 FLAG 密文。
>
> 本方法论不绑定任何具体题目常量，下次遇到同类型新题照此流程推即可。

---

## 0. 一句话本质

这类题不是"密码学"，是**编码学**。出题人把明文拆块、每块做可逆的位级打乱，
再套一层固定模板（骨架）伪装成随机。逆向 = 把每一层"剥"下来。
**关键认知：所有变换都是确定性的、无密钥熵的，已知样例足以唯一反推全部参数。**

---

## 1. 识别题型（看到这些特征就走本流程）

- [ ] 密文长度是某个小整数（如 6）的整数倍
- [ ] 把密文按块切开后，**某些位置的字节/半字节在所有块里固定不变**（骨架）
- [ ] 有 ≥2 组已知明文↔密文，且明文长度不同（用来暴露尾块行为）
- [ ] 密文里出现"半字节级"的规律（高 4 位/低 4 位分别变化）

> 反例：如果密文长度 == 明文长度、无块结构、或用了标准算法（AES/RSA/RC4），
> 不走本流程，转标准密码识别。

---

## 2. 五步推导法

### 步骤 1：定块结构 —— 找骨架，分离有效位
把多组密文按块对齐，逐半字节比较：
- **所有块都相同的半字节** → 骨架（固定模板，无信息）
- **随明文变化的半字节** → 有效数据位

产出：每块 `有效位位置列表`（如本题完整块是 nibble 索引 0,2,3,5,8,10）。

> 技巧：用同一明文的不同部分、或全零/全 'A' 明文，能快速暴露哪些位是骨架。

### 步骤 2：定分块 —— 明文怎么切成块
- 密文块数 == `ceil(len(明文) / N)`，反推 N。
- 观察"块顺序"：本题是**从右往左**分块、**从右往左**输出（最右明文块在最右密文块）。
  判断方法：改明文第 1 字节，看哪个密文块变 → 定位最左明文块对应的密文块位置。

### 步骤 3：定密钥/变换 —— 反推位级映射
对**单字节样例**（最简单）反推变换：
- 设明文字节拆成 (H, L) 两个半字节，密文有效位是 (a, b)。
- 枚举 `(a, b) = f(H, L)` 的可能形式：交换与否 + 各加偏移 mod 16。
- 本题两种：`key=1: (H,L)->(L+4, H+5)`，`key=2: (H,L)->(H+5, L+4)`。
- **密钥周期**：多样例对比，发现 key 按 `1,2,1` 周期循环（即密钥串 "121"）。

产出：逆变换 `inv(a, b, key)` + 密钥周期序列。

> 技巧：用 `derive_solver.py` 的 `probe_block()` 自动暴力搜 (位置, 密钥, 偏移, 重排)。

### 步骤 4：定位置重排 —— 块内字节顺序怎么打乱
比较"明文块内字节顺序"与"解出的有效位顺序"：
- 本题完整块：`ABC -> CAB`（右循环 1 位），解密则左循环 1 位。
- 两字节块：`AB -> BA`（反转）。
- 单字节：不变。

产出：每种块长对应的重排/逆重排规则。

### 步骤 5：定尾块 —— `len % N` 决定特殊结构
尾块（不足 N 字节）的有效位位置**与完整块不同**，必须单独 probe：
- 本题单字节尾块取 (n8, n10)；两字节尾块取 (n4, n6, n7, n9)。
- 用对应 `len % N` 的已知样例反推（如 `2026` 长度 4 → 余 1，暴露单字节尾块）。

产出：尾块有效位位置表（按 `len % N` 索引）。

## 3. 验证（必须做，防止自嗨）

1. **样例全过**：用推得的解密器解所有已知样例，必须 100% 还原明文。
2. **FLAG 合理性**：解出的 FLAG 应符合 flag 格式（如 `flag{...}`），
   且内部字符串可读。若 FLAG 大部分对、个别字节错 → 多半是尾块位置/密钥对齐错了。
3. **逐字节定位**：若只有第 1 字节错，问题几乎一定在"最左/最右尾块"的处理。

---

## 4. 常见坑（本题踩过的，下次直接避开）

| 坑 | 现象 | 解法 |
|---|---|---|
| 块顺序搞反 | 明文整体逆序 | 改明文第1字节看哪个密文块变，定位方向 |
| 密钥流对齐错 | 每块第1字节错 | 密钥是按半字节**全局连续**推进，不是每块重置 |
| 尾块当完整块 | 尾块字节全错 | 尾块有效位位置独立，必须单独 probe |
| 骨架位置算错 | 半字节取错 | nibble 索引 = byte*2 + (高0/低1)，别搞反 |
| 重排方向错 | 块内字节顺序错 | 加密右循环→解密左循环，别用反 |

## 6. 可复用检查清单（遇到新题逐项过）

- [ ] 密文是否定长块倍数？切快找骨架
- [ ] 有几组已知样例？长度是否覆盖不同 `len % N`？
- [ ] 单字节样例反推位级变换 + 偏移
- [ ] 多样例对比找密钥周期
- [ ] 定位块顺序方向 + 块内重排模式
- [ ] 单独 probe 每种尾块（`len % N`）的有效位位置
- [ ] 解密器解所有样例必须全过，再解 FLAG
- [ ] FLAG 个别字节错 → 回头查尾块/密钥对齐
