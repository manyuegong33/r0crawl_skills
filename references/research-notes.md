# Research Notes and Capability Extraction

This collection is informed by public reverse-engineering and agent-skill ecosystems, but it does not copy their prompts, personal names, private paths, secrets, or repository-specific orchestration.

## Capability themes extracted

- Android reverse engineering: static/dynamic tooling, malware analysis, firmware/kernel, obfuscation, CTFs, and cloud/API reversing.
- Agentic malware analysis: case directories, ranked evidence, validated hypotheses, component maps, and multi-phase orchestration.
- Android-focused skills: phase-based workflows, setup guides, JADX usage, memory unpacking, and runtime validation.
- Malware analysis skills: staged payload handling, static/dynamic analysis, network traffic, detection engineering, reporting, and safe lab procedure.
- Game security: user/kernel split, drivers, IOCTLs, callbacks, integrity checks, protected binaries, and anti-cheat analysis.
- General reverse-engineering lists: Windows/Linux/macOS/Android/iOS/IoT coverage, unpacking, emulation, obfuscation, firmware, and protocol analysis.

## Non-binding rule

The names above are research inputs, not runtime dependencies. r0crawl_skills remains vendor-neutral and author-neutral: it routes by observable artifact, platform, goal, and evidence rather than by another project's skill names.

## Local capability extraction

The local skill set was treated as an input for capability discovery only. The extracted themes are generic: syscall and signal evidence, early loader tracing, anonymous executable memory, DEX/ODEX/VDEX relationships, dump-fix validation, JNI registration recovery, hardware-breakpoint observation, cross-platform preflight, experiment notes, artifact manifests, and regression checklists. No personal names, private paths, secrets, custom system identifiers, or repository-specific prompt text are runtime dependencies.
