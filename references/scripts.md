# Script Index

These helpers are intentionally small and dependency-light. They are starter utilities, not replacements for specialist tools.

| Script | Purpose |
|---|---|
| `init_case.py` | Create a reproducible case directory. |
| `hash_artifact.py` | Print SHA-256 and file size. |
| `scan_strings.py` | Extract ASCII and UTF-16LE strings. |
| `parse_har_fields.py` | Summarize HAR requests, fields, and responses. |
| `compare_jsonl.py` | Compare parity fixture JSONL files. |
| `redact_capture.py` | Redact common tokens and cookies from text captures. |
| `validate_dump_manifest.py` | Validate dump metadata and SHA-256. |
| `module_router.py` | Suggest modules from a short task description. |
| `check_toolchain.py` | Show optional tool paths. |
| `generate_report.py` | Generate a case file inventory report. |
| `frida_observe_template.js` | Observation-only Frida starter template. |
| `js_hook_template.js` | Browser fetch observation starter template. |
| `ida_export_template.py` | IDAPython function export starter. |
| `ghidra_headless_template.py` | Ghidra automation starter. |
| `index_skills.py` | Generate `references/generated-index.md`. |
| `check_utf8.py` | Verify UTF-8 readability. |
